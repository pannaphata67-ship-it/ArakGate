# ArakGate

คู่มือใช้งาน
1. หน้า Dashboard (หน้าหลัก)
หน้านี้แสดงสถิติรวม (จำลอง)

กดปุ่ม "Testing" ด้านล่างสุด เพื่อเริ่มจำลองสถานการณ์มีสายเรียกเข้า

2. หน้า Incoming Call (สายเรียกเข้า)
จำลองหน้าจอมือถือเวลามีคนโทรมา

กดปุ่มสีฟ้า "ให้ Arak คุยแทน" เพื่อรับสายและเปิดระบบ AI

(ปุ่มรับสายสีเขียว/แดงทั่วไป จะเป็นการจำลองวางสายหรือรับสายแบบปกติไม่ได้เปิด AI)

3. หน้า Active Call (ขณะคุยสาย)
ระบบจะขออนุญาตใช้ไมโครโฟน (ต้องกด Allow/อนุญาต)

ให้คุณลอง พูดภาษาไทยใส่ไมโครโฟน (เช่น "สวัสดีครับ โทรมาเรื่องอะไรครับ", "คุณเป็นใคร")

ระบบจะแปลงเสียงเป็นข้อความและส่งไปวิเคราะห์

คุณสามารถกดไอคอน 💬 (Bubble) เพื่อเปิดดูหน้าแชทการวิเคราะห์ได้

4. หน้า Chat Detector (ผลวิเคราะห์)
แสดงบทสนทนาที่คุณพูด (ฝั่งขวา)

แสดงคำตอบจาก AI (ฝั่งซ้าย) พร้อมเสียงพูดตอบโต้

ดูแถบสถานะด้านบน:

🟢 Safe: ปลอดภัย

🟡 Analyzing: กำลังวิเคราะห์

🔴 Error/Danger: มีความเสี่ยงสูง (มิจฉาชีพ)



วิธีการติดตั้งและรันโปรแกรม (Installation)

ติดตั้ง Library ที่จำเป็น เปิด Terminal หรือ Command Prompt แล้วพิมพ์คำสั่ง:  pip install flask flask-cors python-dotenv google-generativeai

ตั้งค่า API Key  สร้างไฟล์ชื่อ .env ไว้ในโฟลเดอร์เดียวกับ server.py

ใส่โค้ดนี้ลงไป (แทนที่ YOUR_API_KEY ด้วยคีย์ของคุณ): GEMINI_API_KEY=YOUR_API_KEY_HERE

เริ่มรันเซิร์ฟเวอร์ พิมพ์คำสั่ง: python server.py
